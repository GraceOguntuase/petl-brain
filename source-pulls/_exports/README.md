# Raw exports — brand-provided data Parker MCP does not carry

Parker MCP returned no customer reviews and no post-purchase surveys for NOBL when tested on 2026-09-17. These files stand in for the review surface.

- `reviews-trustpilot-2026-08-18.csv` — 3,127 rows, review dates 2024-06-22 to 2026-08-13.
- `reviews-okendo-2026-08-18.csv` — 113 rows, review dates 2026-06-13 to 2026-08-12.
- `review-export-summaries.md` — the export's own summary tabs, transcribed.

Source: `Copy of NOBL_Product_Feedback_Combined.xlsx`, provided by Grace (NSY Digital), file dated 2026-08-18. Brand/agency-provided export (**stated**), converted to CSV verbatim.

Columns: Review Date, Customer Name, Star Rating, Product Mentioned, Product Feedback, Feedback Type, Product Theme, Specific Product Issue or Praise, Customer Usage Context, Review Link.

**Read these limits before using the data (verified by inspecting the files, 2026-09-17):**
- **Every row is 5 stars** (3,127 of 3,127 Trustpilot; 113 of 113 Okendo). The export is filtered to 5-star, product-related reviews. There are no 1–4 star reviews here, so complaint frequency, star distribution, and detractor language cannot be read from this file. Treat any "negative" read as data-limited.
- "Product Feedback" appears to be the product-related portion of each review, not necessarily the full review text. Full text is at the Review Link where one is given.
- Feedback Type (Trustpilot: 2,823 Positive / 180 Negative / 124 Mixed; Okendo: 103 / 1 / 9) and Product Theme were classified before the export, by an unknown process. Treat them as stated labels, not verified coding.
